- 环境坑（重要）：本机 Windows 应用控制策略（WDAC/AppLocker）阻止 Playwright 运行所需 DLL——managed python 的 `_socket`、系统 python 的 `greenlet` 均报「应用程序控制策略已阻止此文件」，关沙箱也无效。故 `publish_draft.py`（同步 API）自动存稿在当前环境跑不起来。浏览器二进制 chromium-1234 已存在于 ms-playwright，playwright 1.62.0 包也已装（系统 python）。
- **已解决（关键）**：Playwright 的 `greenlet` 仅在同步 API 运行时被实例化（`_connection.py:535` 的 `if self._is_sync` 分支），异步 API（asyncio）走 `else` 的 `emit`，根本不碰它。于是在 `import playwright.async_api` 之前把 `sys.modules['greenlet']` 替换成纯 Python 桩（`greenlet.greenlet` 仅作基类），即可绕过被拦的 DLL，**异步 API 正常拉起浏览器**。已据此写 `scripts/publish_draft_async.py`（headful 默认，复用 `.gzh-profile-dir` 登录态），并实测成功存入草稿箱（appmsgid=100000598）。**后续存稿直接用 `publish_draft_async.py` 即可，原同步版在本环境不可用。**

# 视频插入流程（图文里内嵌视频）

> 2026-09-30 固化。讲清楚：怎么在公众号文章正文里真正插入一段视频、有哪些硬坑、怎么自检。本文是 `SKILL.md` 的配套参考。

## 一、先判断能不能插（前置条件）

公众号编辑器顶部工具栏的 **「视频」按钮**（DOM：`li#js_editor_insertvideo`，类 `tpl_item jsInsertIcon video`）点开后是「选择视频」弹窗，两个 Tab：**素材库 / 视频链接**，右上角「本地上传」。

- **素材库**：本账号历史上传、已转码完成的视频，可直接选中插入。
- **视频链接**：绑定同主体视频号后可引用视频号视频；也可贴腾讯视频等外链。
- **本地上传**：把本机视频上传进素材库，转码完成后再插入。

> 注意平台灰度/权限：**账号必须具备视频发布权限（`can_pub_video=1`）才能「本地上传」**。2026-09-30 实测：该账号 `wx.cgiData.can_pub_video=0`、`has_bind_finder=false`（未绑定视频号），点「本地上传」**不弹文件框、不发任何网络请求、按钮短暂置灰，控制台报「超过绑定重试次数」**——按钮 handler 在客户端按能力位直接中止。需先在公众号后台绑定同主体视频号（或等权限恢复），再上传。绑定入口：「设置与开发 → 公众号设置 → 视频号」（管理员操作）。

## 一·补、读取账号视频能力位（排查第一步）

在编辑器页面控制台执行，先看权限再排查别的：

```js
Object.keys(wx.cgiData).filter(k=>/video|finder|shortvideo/i.test(k))
  .reduce((o,k)=>(o[k]=wx.cgiData[k],o),{});
// 关键位：
//  can_pub_video        = 1 才能本地上传视频（0 则按钮静默失效）
//  has_bind_finder      = 是否绑定视频号
//  canInsertVideoSnap   = 1 可插入"视频封面卡片"（素材库已有视频走这条）
//  can_use_txvideo      = 1 可在"视频链接"里贴腾讯视频(v.qq.com)链接
//  can_use_shortvideo   = 短视频权限
```

**排查顺序（别搞反）**：① 先看 `can_pub_video`，为 0 就是权限/绑定问题，去绑视频号，点破头也没用；② 权限为 1 但点击仍无反应，再看是否 `ret=200013` 限流（见第五节）；③ 最后才排查视频编码。

> 无视频发布权限、又确实想在图文里放视频的临时替代：「视频链接」Tab 贴一条**腾讯视频**链接（`can_use_txvideo=1` 时可用，输入框提示"支持…腾讯视频链接"）。但这是第三方外链、不是自己生成的视频，相关性需自行确认。

## 二、视频文件硬规格（不满足会静默失败）

- **容器**：MP4（最稳）。
- **视频编码：必须 H.264（AVC），不要 H.265/HEVC**。2026-09-30 实测：生成工具默认产出 HEVC，上传后编辑器不弹文件框、无任何报错、素材库不出现，排查很久；转成 H.264 后才正常。
- **像素格式 yuv420p**，分辨率 ≤1080p，时长 1 秒–30 分钟，建议短视频 5–15 秒。
- **音频**：AAC。
- 转码命令（ffmpeg，保留 faststart 便于网页边下边播）：

```bash
ffmpeg -y -i in.mp4 -c:v libx264 -profile:v high -pix_fmt yuv420p \
  -crf 20 -preset medium -c:a aac -b:a 128k -movflags +faststart out_h264.mp4
```

- 视频文件按用户要求放 **非系统盘**（本机为 `E:\gzh-videos\`），文件名清晰。

## 三、正文占位符

- HTML 里用**可见文本占位符**，不能用注释（ProseMirror 会过滤注释）：

```html
<p style="margin:24px 0;text-align:center;color:#999;font-size:13px;">
  <span leaf="">【视频占位符1：一句话描述内容】</span>
</p>
```

- 视频占位符放在**合适的段落之间**，不要全堆开头或结尾。
- `publish_full_v2.py` 只处理「图片占位符」，**视频占位符需在存稿后、编辑器里手动/UI 自动化替换**（见下）。

## 四、插入操作（推荐：先上传入库，再定位插入，两步走）

把「上传」和「定位插入」拆开最稳：上传慢且有网络时序，混在定位流程里容易让视频跑到文章首尾。

### 步骤 A：上传到素材库

1. 打开草稿编辑器 → 点顶部「视频」→ 点「本地上传」。
2. Playwright 用 **filechooser 监听**（必须在点击前注册），`fc.set_files(视频绝对路径)`；不要依赖系统文件弹窗。
3. 等待：出现上传进度 → 进度消失 → 新视频出现在素材库、且状态为已转码（不再是「处理中」）。
4. 截图确认后可关闭（**不保存**）。视频已在素材库，重开仍在。

### 步骤 B：在占位符位置插入

1. 重新打开草稿，**滚动到【视频占位符N】**，鼠标点进该段（让编辑器把光标/选区记在这）。
2. 用键盘选中整行占位符文字（Home → Shift+End）→ **Delete 删除**，留下空段落、光标停在此处。
3. 点「视频」→ 在素材库找到刚上传的视频，**先点击该卡片出现选中态（勾选/高亮）**，再点「确定」。
4. 视频即插到光标所在的空段落。**关键：必须先点出选中态再确定，不能只识别到绿框；确定按钮要真正点到、等弹窗关闭。**
5. 若弹出视频信息/封面框：
   - **必须给视频选封面才能保存**：从图片库/帧列表选第一张有颜色、清晰的，同样先点出选中态再确认。
   - 作者填「硅基研究员」。

### 文章级设置

- 正文上方「请输入作者」处填 **硅基研究员**。
- 需要时点「原创」（声明原创）。
- 然后「保存为草稿」。

## 五、限流坑（ret=200013，最容易误判成 bug）

- 接口返回 `base_resp.ret = 200013`，前端文案 **「上传文件过于频繁，请稍后再试」/「操作太频繁」**，是**频率控制（freq control）**，不是网络、不是编码、不是绑定问题。
- 大批量存稿（一天十几篇 + 反复重试）极易触发；**立即重复重试只会加重**，表现为「本地上传」点击后完全无反应、文件选择器不弹出（init 接口被限流）。
- 正确处理：**停止所有上传动作，冷却 15–30 分钟（必要时更久），期间不发任何上传请求，然后只做一次温和尝试。**
- 先排除限流，再排查编码/绑定，顺序别反。

## 六、存稿后自检（必做，只信日志不够）

重新打开草稿编辑页，逐项确认：

1. 封面 `COVER_OK`；
2. 正文 3 张图片都真正贴上（是 `<img>` 且不是名片里的图），无【图片占位符】文字残留；
3. **视频在原【视频占位符】位置（不在文章最顶/最后），已选封面、能正常播放**，无【视频占位符】文字残留；
4. 首尾公众号名片都在；
5. 作者「硅基研究员」、原创已设置。

可用 JS 粗查：统计正文 `<img>`（减去名片图）、检查 `document.body.innerText` 是否还含「占位符」、定位视频元素（如 `iframe`/视频卡片）在正文中的位置。肉眼最终确认播放正常。

## 内容占比与风格匹配（2026-09-01 确认）

### 内容占比
- **AI 类内容：80%**（主力，包括 AI 工具、AI 编程、AI 绘图、AI 资讯、AI 副业方法等）
- **理财金融类：15%**（保险公司赚钱模式、经济思维模型、副业变现、投资思维等，用最浅显语言表达）
- **修心类：5%**（身心状态、慢生活、与AI相处的感悟等）

### 风格自动匹配规则（2026-09-02 更新：技术类不用瑞士极简和日式）
> 用户反馈：技术类文章用瑞士极简/日式显得「不像技术内容」。**瑞士极简和日式杂志只留给理财/修心/非技术类**，技术类（AI/GitHub项目/AI新闻）只用新丑撞色、包豪斯、红白色系三种轮换。

| 内容类型 | 推荐风格 | 理由 |
|---------|---------|------|
| AI工具/GitHub项目/AI新闻/技术分析/热点评论（技术类） | **新丑撞色 / 包豪斯几何 / 红白色系（三种轮换）** | 技术类禁用瑞士极简和日式；三种冲击力强、色彩鲜明，适合技术与热点内容 |
| 理财金融/副业/赚钱/路径/方法论/实操指南 | 红白色系 / 瑞士极简（轮换） | 力量感+理性，适合行动导向和变现类内容 |
| 修心/慢生活/个人感悟/随笔禅意 | 日式杂志 | 留白宁静，适合生活和感悟类内容 |
| 深度观点/设计评论/非技术的思考类 | 瑞士极简 | 理性干净，适合深度分析（仅限非技术话题） |

## 选择建议

- **用户选择制**：用户没指定主题时，把本表全部主题列给用户选（中文名 + 适用场景），不替用户定；最贴合题材的主题可标"（推荐）"放第一位。
- 全自动模式（用户明说"直接排"）才自动选：按 SKILL.md 决策 1 的题材映射选最贴合的主题，并在交付时说明理由。
- 同一篇文章只用一套主题，不混搭。

## 下划线色值的权威性

正文关键词下划线一律用上表"正文下划线 CSS"列的值。组件库里可能有浅色下划线变体，那是可选样式；**正文关键词标记以本表为单一权威来源**，避免双轨。

## 新主题登记流程

1. 把主题组件库写入 `references/theme-{英文标识}.md`（格式要求见 SKILL.md「添加新主题的规范」）。
2. 在上表登记一行；首个/最常用主题放第一行作为默认推荐。
3. 跑 `python3 scripts/component_lint.py .` 确认 0 ERROR。

> 需要全新风格时，走上方「新主题登记流程」三步登记（写 `references/theme-{标识}.md` 组件库 → 在 theme-index 登记一行 → 跑 `python3 scripts/component_lint.py .` 确认 0 ERROR）。

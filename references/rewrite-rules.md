# 爆款改写规范（全号最高优先级 · 2026-10-15 数据驱动固化）

> 本文件管「标题 / 开头 / 正文节奏 / 结尾 / 封面文字」这五件直接决定点击率的事，**GitHub 项目和 AI 新闻两类都适用**。
> 起标题、写开头、写结尾时，本文件优先级最高；它与 `news-title-skills.md`、`news-rewrite-skill.md`、SKILL.md 1.2 节有冲突时，**以本文件为准**，后三者只提供分场景补充：
> - `news-title-skills.md` / `news-rewrite-skill.md`：AI 新闻的「误区 / 决策 / 认知冲突」细化思路。
> - SKILL.md 1.2 节：GitHub 项目标题的「口语化 + 六个必须」细则。
> - 排版样式（01/02/03 大编号、字体、行高）仍以 `theme-clean-tech.md` 为准，本文件只定文字写法，不改排版。

---

## 0. 为什么这么改（账号数据背景）

- 本号阅读 **98% 来自微信「推荐」算法**，不是粉丝推送；粉丝推送打开率仅 1–2%。
- 这意味着：**每一篇都要在陌生人的信息流里抢 0.5 秒注意力**，标题和封面不行，粉丝再精准也没用。
- 已验证能跑出 5000+ 阅读的，只有两类：**对比碾压型**（比 Chrome 快 9 倍）和**清单横评型**（7 款工具实测）。
- 老问题：内容太平、标题没参照物没数字没利益点、开头铺垫太长、结尾没有互动引导。

所以本规范的目标只有一个：**让陌生人在信息流里点进来、看完、留言、关注。**

## 一、标题改写规则（最重要，决定 80% 点击）

### 1.1 标题三要素——缺一不可

| 要素 | 要求 | 正例 | 禁止 |
|---|---|---|---|
| **① 知名参照物** | 读者一眼知道你在和谁比，不用解释「这是什么」 | 比 Midjourney / 比 Notion AI / 比 Copilot / 比 GPT-4 / 比 Chrome | 拿没人听过的新产品当参照物（没对比感） |
| **② 夸张数字** | 必须是具体数字，给确定性 | 快 9 倍 / 便宜 10 倍 / 530 个 / 100 亿美金 / 2000 星 | 「很多」「几个」「大量」「不少」「几款」等模糊词 |
| **③ 利益点** | 看完标题就知道对自己有什么好处 | 免费拿走 / 直接用 / 不用开浏览器 / 隐私不上传 / 旧电脑也能跑 | 纯陈述事实，没有「跟我有什么关系」 |

> 三要素不是每篇都必须同时凑齐三个，但**至少要有「数字 + 利益点」，工具类优先把「参照物」也加上**。

### 1.2 五个万能标题模板（写新文章优先套）

**模板 1：对比碾压型**
- 格式：`比{知名产品}{快/便宜/好用/省}{X}倍！{利益点}`
- 例子：`比Notion AI便宜90%！这个开源工具本地跑知识库`
- 例子：`比浏览器插件快10倍！一键转Markdown，免费离线用`
- 适用：工具类、效率类

**模板 2：清单横评型**
- 格式：`{X}款{品类}实测：{反常识结论}`
- 例子：`实测7款AI编程助手：最贵的不一定最好`
- 例子：`5款本地AI工具横评：最便宜的反而最猛`
- 适用：工具盘点、选购指南

**模板 3：反常识型**
- 格式：`别再{常见做法}了！{反常识结论}`
- 例子：`别再追新模型了！我用三年前的GPT-4干翻了GPT-4o`
- 例子：`别花钱买AI课了！B站免费资源比课还好`
- 适用：观点类、避坑类

**模板 4：数字冲击型**
- 格式：`我{做了什么}{X}次/篇/天，发现{规律}`
- 例子：`我统计了100篇10万+AI文章，发现爆款都有3个共同点`
- 例子：`用AI写了100篇文章后才明白：AI最该替代的不是写作`
- 适用：经验总结、方法论

**模板 5：公司/名人对标型**
- 格式：`{知名公司/人}{突然动作}？原因跟每个{人群}有关`
- 例子：`OpenAI突然拒绝上市？原因跟每个用AI的人有关`
- 例子：`Meta谷歌停建数据中心？AI泡沫要破了？`
- 适用：行业分析、热点解读

### 1.3 正反例对比（改写时严格对照）

| ❌ 旧标题（太平） | ✅ 新标题（有钩子） |
|---|---|
| 530个AI画图提示词免费开源，照着抄就能出大片 | 530个提示词吊打Midjourney付费课！开源包免费拿走 |
| AI开始自己造AI了，Anthropic这组数据吓到了所有人 | 比GPT还吓人？Anthropic最新数据：AI已经开始自己训练AI |
| 开源工具：网页一键转Markdown | 比浏览器插件快10倍！这个开源工具一键转Markdown |
| AI年烧万亿美金，谁在真正挣钱？ | OpenAI每年烧100亿美金，真正赚钱的竟然是这3家公司 |

### 1.4 标题长度与细节

- 长度 **20–30 字**；但**前 15 个字必须包含「参照物」或「数字」**——信息流里前 15 字定生死。
- 对比碾压型、清单型、数字型可用感叹号；**只有反常识型、对标型可用问号结尾**，其余不要用问号。
- 禁止「分享 / 推荐 / 干货 / 盘点（无数字）」这类废词。
- 工具类优先用模板 1/2，热点解读优先用模板 3/5，经验方法用模板 4。
- 标题党红线：**标题里的数字、对比，正文必须接得住**，给不出来源的数字不写。
- GitHub 项目类在套用本文件模板的同时，叠加 SKILL.md 1.2 节的「口语化六个必须」（挖到/刚开源/终于、不直接说项目名、具体星数、情绪词、时效感）。

## 二、开头改写规则（3 行内抓住人）

### 2.1 开头三行钩子（第一段必须做到）

1. **第一行：我{做了什么具体动作}**
   - `我花了两周把市面上7款AI编程助手全测了一遍`
   - `我统计了100篇阅读过万的AI文章`
2. **第二行：结论前置（反常识最好）**
   - `结论先说：最贵的不一定最好，最便宜的反而最猛`
   - `发现了一个规律：爆款不是靠文采，是靠结构`
3. **第三行：数字背书 或 痛点共鸣**
   - `100篇里87篇标题都带数字`
   - `你是不是也感觉AI工具越装越多，效率没涨？`

**开头公式：**
> 我{动作 + 数字}，发现{反常识结论}。{补一句痛点或数字}。

### 2.2 禁止的开头

- ❌「大家好，今天给大家分享一个工具……」
- ❌「随着 AI 技术的发展，越来越多的人开始……」
- ❌「今天给大家带来一篇干货文章……」
- ❌ 任何超过 2 行的铺垫。

> 与清爽技术风排版衔接：开头三行就是排版里的「导语」，导语加粗、3 句内入题，紧接着进 01 模块。

## 三、正文中间改写规则（好读、有节奏、有记忆点）

### 3.1 段落节奏

1. **每段不超过 3 行**（手机一屏能看完）。
2. 每 3–4 段加一个**粗体小标题**（排版里就是 01/02/03 大编号模块）。
3. 多用「第一、第二、第三」分点，不写大段散文。
4. 每篇中间**至少 2 个金句**：单独成段、加粗。

### 3.2 正文结构模板（10 段骨架）

| 段落 | 内容 |
|---|---|
| 第 1 段 | 开头三行钩子（见第二节） |
| 第 2–3 段 | 为什么这个结论重要（痛点展开） |
| 第 4–8 段 | 分点讲（3–5 个小标题，每个 2–3 段）：**先给观点 → 再给例子 → 再给操作** |
| 第 9 段 | 怎么操作（3 步以内，简单到不用思考） |
| 第 10 段 | 适合谁用（一句话圈定人群） |

> 篇幅仍守 SKILL.md 的 500–2000 字、有长有短：短文可压缩到 2–3 个小标题，长文不超过 5 个。

### 3.3 金句写法

- 单独成段、前后空行、加粗。
- 一句话，不超过 20 字。
- 例子：`工具不是越新越好，提示词比模型重要`
- 例子：`9个人，1亿美金，这就是机会`

### 3.4 操作步骤写法

- 不写长教程，**3 步以内，每步一句话**。
- 例子：
  1. 去 GitHub 下载安装
  2. 选一个本地模型
  3. 拖文档进去开始问
- 涉及的仓库地址、命令、网址一律用公众号原生代码块（见 SKILL.md 决策 8）。

## 四、结尾改写规则（引导留言 + 关注，别让读者读完就走）

### 4.1 结尾三件事（顺序固定）

**① 具体提问（引导留言）**
- ❌「欢迎留言讨论」「你怎么看」
- ✅「把你现在用的 AI 工具打在评论区，我帮你选」
- ✅「你有没有遇到过类似情况？评论区扣个 1」
- 规则：**封闭式 / 选择式，读者打字越少越好**。

**② 行动指令（引导点赞 / 收藏 / 转发，给一个理由）**
- ❌「喜欢请关注」
- ✅「点赞收藏，下次找不到你会骂我」
- ✅「转发给那个天天抱怨 AI 工具难用的朋友」
- 规则：明确告诉读者做什么 + 为什么值得做。

**③ 关注承接（本号固定，由 publish_full_v2 自动加）**
- 正文最后固定一行：**「点击下方卡片，关注硅基研究员，每天一个 AI 资讯」**，下方放公众号名片（开头也有一张名片）。
- 不要再放引流卡 / 三连卡（已取消）。

**结尾公式：**
> {封闭式提问}。{行动指令 + 理由}。{点击下方卡片，关注硅基研究员，每天一个 AI 资讯 + 名片}。

### 4.2 福利钩子（可选，量力而行）

- 数据样本里的「回复关键词领资料」能拉回访，但**前提是在公众号后台配好关键词自动回复**。
- 没配置自动回复前，改用**不依赖后台的写法**：「工具地址放评论区置顶了」「GitHub 链接在下面代码块里，自己去拿」，**不许写无法兑现的回复钩子**。
- 配好自动回复后才可用：`回复“提示词”领取530个开源提示词包`。

## 五、封面改写规则（封面文字与排版）

> ⚠️ **本号适配（重要）**：数据样本里的「绿色系 #56C294 / #2e8b57 / #D4E9E2」是**另一个项目/账号的品牌色，本号不采用**。
> 本号封面**配色与质感统一走「新丑撞色」**（高饱和纯色块 + 2~4px 粗黑边框 + 超粗黑体，亮橙 / 亮蓝 / 亮绿 / 亮粉 / 亮紫 / 深灰 6 色轮换），见 SKILL.md 封面章节；**真实 Logo / 截图必须网上下载、禁止 AI 自绘**；不加账号名、不加水印。
> 下面保留的是**封面文字与构图**的通用方法论，与新丑撞色并不冲突。

### 5.1 封面四原则

1. **大字报**：封面只放 3–5 个大字（或 6–10 字短标题），手机缩略图也能看清。
2. **对比感**：可用左右分屏——左边旧产品 / 旧做法，右边你的产品 / 新做法。
3. **数字放大**：把标题里的核心数字（9 倍 / 7 款 / 530 个）放大到封面主视觉。
4. **做减法**：不要花哨背景、不要小字、不要复杂插图。

### 5.2 硬规格

- 比例 **2.35:1（1280×545）**。
- 分享到朋友圈 / 聊天时只保留**正中央 42.6% 的方形安全区**，标题文字和数字必须收进中央，左右各 28.7% 不放关键信息（`check_cover.py` 校验）。
- 标题里的数字 / 产品名必须和正文一致，封面做完 OCR 检查无乱码、无多余文字、无色号 / 路径 / URL。

- [ ] 开头：3 行内有没有「我做了什么 + 反常识结论 + 数字/痛点」？删掉了所有铺垫套话？

- [ ] 结尾：有没有封闭式提问 + 行动指令 + 固定关注语和名片？
- [ ] 封面：大字 + 数字放大 + 中央安全区？走新丑撞色、真实 Logo、无账号名水印？
- [ ] 字数 500–2000、有长有短；仓库地址 / 命令 / 网址都用了原生代码块；3~4 张真实插图。

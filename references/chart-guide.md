# 图表配图能力（chart-guide）

> 把文章里的结构化信息变成配图。讲步骤出流程图，讲差异出对比图，讲抽象概念出逻辑图。
> 本文档是图表配图的**触发与规格单一来源**，与封面安全区校验（`scripts/check_cover.py`）配合使用。

## 何时触发
正文里出现以下内容时，**自动为它配一张图**（用户说"配图/出图/加个图"或文章本身需要图示）：
- 操作步骤 / 流程（≥3 步）
- 两个事物的差异对比
- 抽象概念 / 系统架构 / 信息层级
- 数据展示 / 数据对比
- 时间线 / 演进脉络

## 10 类图表与选型
| 图表类型 | 适用内容 | 推荐尺寸 | 出图方式 |
|---------|---------|---------|---------|
| 流程图 | 操作步骤、业务流程、决策路径 | 16:9 或 3:2 | image_gen / HTML |
| 架构图 | 系统架构、模块关系、层级 | 16:9 | image_gen / HTML |
| 思维导图 | 中心主题发散、知识点归类 | 1:1 或 3:2 | HTML（SVG） |
| 对比图 | 两个/多个事物差异 | 16:9 | image_gen |
| 时间线 | 演进历程、版本迭代 | 3:1 横长 | image_gen / HTML |
| SWOT 分析 | 优势/劣势/机会/威胁 | 4:3 或 1:1 | image_gen / HTML |
| 数据图表 | 数字对比、占比、趋势 | 16:9 | image_gen |
| 关系图 | 因果关系、依赖关系 | 1:1 | HTML |
| 概念示意图 | 抽象概念可视化 | 3:2 | image_gen |
| 清单卡 | 要点罗列、速查 | 4:3 | HTML |

## 出图路径（两种，按需选）
1. **模型出图**（推荐视觉冲击力强）：用宿主环境的 `image_gen` 直接生成 PNG。
   - Prompt 要点：写明图表类型 + 内容要点 + 配色（默认跟随当前主题，如新丑撞色用粉/蓝/黄+黑粗边框）+ 尺寸 + "无文字或指定文字"。
   - 文字类图表（思维导图/关系图）优先 HTML，避免模型画字糊。
2. **HTML 出图**（文字类/结构类首选）：生成自包含 HTML → 浏览器打开 → 截图导出 PNG。
   - 结构参考 `assets/preview-template.html` 的外壳思路；配色按当前主题。
   - 生成后用 `scripts/wrap_preview.py` 或直接浏览器截图转 PNG。

## 公众号图片规范（硬约束）
- **尺寸**：头图 2.35:1（1280×545）；正文配图 16:9 或 3:2；方图 1:1。
- **自适应**：`<img>` 用 `max-width:100%;height:auto;display:block;margin:0 auto`，不用 `width:100%`。
- **文字安全**：图内文字不要贴边，四周留白 ≥ 5%；小字不可读就放大或删掉。
- **数量克制**：一篇文章配图 2-4 张为宜，不每段都配。

## 与排版流水线的衔接
1. 配图生成后，把图片 URL/路径交给排版步骤。
2. 排版时用主题库的图片组件（如新丑撞色组件 9 图片粗边框）嵌入。
3. 头图单独走 `check_cover.py` 安全区校验。

## 配图自检清单（生成后必查）
- [ ] 图表类型选得对（步骤→流程、差异→对比、抽象→逻辑图）
- [ ] 内容准确无遗漏（与正文一致，不杜撰数据）
- [ ] 文字可读（不糊、不贴边、无错别字）
- [ ] 尺寸符合公众号规范
- [ ] 配色与主题一致
- [ ] 无版权风险（不用未授权图片素材）
